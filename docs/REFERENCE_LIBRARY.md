# Reference Library

The Reference Library records useful external ecosystems such as template marketplaces, motion libraries and finishing tools.

It stores **source-level metadata and usage policy**, not copied marketplace content.

Use it for:
- inspiration
- identifying patterns worth recreating internally
- provenance notes
- deciding where to look for a user-licensed asset

Do not use it as a bulk mirror of Canva, Figma Community, LottieFiles, Motion Array, Envato or Adobe assets.
