# Claude Design connection path

Goal: keep the brand Design System authoritative while making this repo available as a creative reference library.

## Recommended flow
1. Keep the existing brand Design System selected in Claude Design.
2. Attach/link this repository as a codebase/reference library where supported.
3. Tell Claude to consult `CLAUDE.md` first.
4. For ambiguous briefs, ask the Creative Director Router for 3–6 template IDs.
5. Select an ID, then let Claude load only that blueprint/recipe.
6. For implementation-heavy motion, hand off the selected project to Claude Code and keep the same IDs.

## Never
- treat this repo as a replacement brand system;
- ingest all packs for every task;
- convert demo content to operational/public data;
- redraw official logos/assets from template placeholders.
