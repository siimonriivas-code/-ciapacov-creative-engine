# Quality bar

A premium resource must pass all of these:
- clear hierarchy at phone size;
- no generic dashboard aesthetics unless the task is UI;
- no decorative motion without narrative function;
- no hidden overflow;
- deterministic behavior with long/short content;
- explicit photo/data/route requirements;
- active brand system can restyle it without code rewrite;
- reduced-motion fallback is possible;
- demo content cannot be confused with production truth.
