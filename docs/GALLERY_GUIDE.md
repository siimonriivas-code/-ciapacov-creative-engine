# Gallery guide — v0.4

The local gallery is designed to reduce prompt iteration:

- **Search** by natural-language brief.
- Use **quick intent chips** for common jobs.
- Filter by content type, Premium or Favorites.
- Tap **★** to save preferred structures in localStorage.
- Tap **↔** to compare up to three templates before choosing.
- Switch to **Campaign Kits** when several coordinated formats are needed.
- Open a template and use **Copy prompt** to send a targeted, low-context instruction to Claude Design.

Favorites are local UI preferences only. They do not change production governance or registry status.
