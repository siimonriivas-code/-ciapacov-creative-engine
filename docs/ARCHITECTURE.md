# Architecture v0.5

```text
ACTIVE DESIGN SYSTEM
  identity · brand · official assets · typography · accessibility
            ↓
CREATIVE DIRECTOR
  structured brief · domain inference · shortlist · asset readiness
            ↓
DOMAIN LIBRARY
  9 work domains · 20 Operational Masters
            ↓
CREATIVE ENGINE
  80 templates · 48 motions · 8 Campaign Kits · renderers
            ↓
ASSET VAULT
  original reusable primitives + semantic slots
            ↓
MEDIA LIBRARY                     REFERENCE LIBRARY
  real photo/video metadata        inspiration + provenance only
            ↓                             ↓
INGEST PIPELINE
  rights check · normalization · hash · registry · contact sheet
```

## Why the layers stay separate
A Design System should not become a warehouse for every photo, motion file, marketplace reference and generic composition. Keeping identity, composition, domain logic, assets and media separate lets the same engine serve different active brands without leaking visual rules between them.
