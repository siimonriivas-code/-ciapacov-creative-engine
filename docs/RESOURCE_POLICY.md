# Resource policy

The Creative Engine may reference external inspiration, but production code/assets are not vendored blindly.

1. Prefer original in-house primitives and layouts.
2. Before importing third-party code/assets, verify license, attribution obligations, redistribution rights and maintenance status.
3. Never copy a commercial template marketplace asset into this repo without an explicit license.
4. Brand assets live outside this engine and are supplied by the active Design System.
5. Remote runtime dependencies are not required for a production export; critical visual assets should be local and licensed.
6. AI-generated imagery is content, not a reusable brand asset, unless explicitly approved.
