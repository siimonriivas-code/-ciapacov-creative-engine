# Generated Visual Catalog

Run:

```bash
npm run contact-sheets
```

This generates `catalog/contact-sheets.html` and `catalog/catalog.json` from the current Domain Library, Operational Masters, Template Registry and Asset Vault.

The HTML contact sheet is intentionally usable offline and does not require Claude or any LLM call. Generated catalog files may be kept local/exported rather than committed, so the registries remain the source of truth.
